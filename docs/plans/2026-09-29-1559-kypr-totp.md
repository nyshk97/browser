# kypr のワンタイムコード（TOTP）を Nemo で使えるようにする

## 概要・やりたいこと

kypr に 5 つ目の種類「ワンタイムコード」（`type: "totp"`, `schema: 1`）を足し、Google Authenticator をやめる（kypr 側の plan: `~/kypr/docs/plans/2026-09-29-1511-totp.md`。仕様は `~/kypr/docs/crypto-spec.md`「ワンタイムコード（TOTP）」）。
kypr の仕様・`packages/crypto`・`packages/client`・Web・iOS は 2026-09-29 に実装した。**この plan は Nemo 側**で、ポップアップからコードを使えるようにする。

- ポップアップの「このページ」に、そのページに合う TOTP をコード付きで出す。押すとフォーカス中の欄に入れる（入れられなければコピー）
- 下の全件検索を「保管庫 / コード」で切り替える
- パスワードを入れたとき、そのページに合う TOTP が 1 件だけならコードを自動でコピーする
- **表示中のページから QR を読んで登録する**（2FA の設定画面の QR。カメラではなく `webContents.capturePage()`）。URL はそのページのオリジン

## 前提・わかっていること

### kypr の /dig で決まったこと（Nemo に関わるもの）

| 論点 | 決定 |
| --- | --- |
| データの形 | ログインと紐づけない独立したアイテム。`name` が発行元・`account` がラベル・`secret`（Base32）・`algorithm` / `digits` / `period`・`uris`（任意） |
| このページの候補 | `uris` を足した TOTP だけが合う（照合はログインと同じ規則。`matchingTotps`） |
| 自動コピー | パスワードを入れたとき、**そのページに合う TOTP が 1 件だけなら**コードをコピーする（短い表示で知らせる。30 秒で消える）。2 件以上ならコピーせず、ポップアップの「このページ」から選ぶ |
| ポップアップ | 上の「このページ」に合う TOTP もコード付きで並べる（押すとフォーカス中の欄に入れ、入れられなければコピー）。下の全件検索は iOS に合わせて「保管庫 / コード」で切り替える |
| 新規登録 | ポップアップの「このページの QR を読む」。表示中の範囲を撮り、`otpauth://totp/` として読める QR だけを拾う。登録画面を開いて、発行元・ラベル・秘密鍵を埋め、URL にそのページのオリジンを入れる。秘密鍵か otpauth URI の貼り付けでも登録できる |
| 表示 | コードは常に出す（伏せない）。並びは発行元 → ラベル（発行元が空のものは末尾）。見出しは「発行元: ラベル」。6 桁は 3 + 3、8 桁は 4 + 4 で区切る。検索の対象は発行元・ラベル・URL |
| 重複 | 秘密鍵のバイト列・アルゴリズム・桁数・周期が同じものがあれば知らせる（`sameTotp`） |

### kypr 側にあるもの（vendoring でコピーされる）

- `crypto/totp.ts`: `totpCode` / `totpProblem` / `totpRemaining` / `base32Decode` / `normalizeTotpSecret`、`crypto/item.ts` の `TotpItem` / `newTotpItem`
- `client/totp.ts`: `parseOtpauthUri` / `totpTitle` / `compareTotp` / `sameTotp` / `totpMatchesQuery` / `formatTotpCode` / `TOTP_PROBLEM_TEXT` / `totpNow`
- `client/url-match.ts`: `matchingTotps`（ゴミ箱・隔離・ログインは除く）
- `client/session.ts`: `EntryState` に `{ kind: "totp"; item: TotpItem }` が増えた
- テストベクタ（`test-vectors/v1.json`）: `totpItem` / `totpItemSparse` / `totp`（RFC 6238）/ `totpUnusable` / `otpauthUris`

### 調べてわかったこと（Nemo のコード）

- kypr の main 側は `src/main/kypr/index.ts`（`kyprSummaries` / `kyprMatches` / `kyprBadge` / `kyprItem` / `copyKyprField` / `saveKyprItem`）、入力は `src/main/kypr/fill.ts`（`fillKyprLogin` / `quickFillKypr` / `kyprDraftFrom`）、ポップアップは `src/renderer/components/Kypr.tsx`
- クリップボードは `src/main/kypr/index.ts` の `clipboardValue` / `clipboardTimer`（30 秒で消す・自分の書いた中身のときだけ）
- 平文は main が必要なときに 1 件ずつ renderer に渡す方針（一覧には表示に要る項目だけ）。**TOTP の秘密鍵は renderer に渡さず、コードだけを渡す**のが今の方針に合う（コードは main で計算する）
- `capturePage` は `src/main/agent/page.ts` で使っている。QR を読むライブラリは Nemo にまだ無い

### 決定事項（kypr のセッションの /dig で確定。2026-09-29）

| 論点 | 決定 |
| --- | --- |
| QR を読むライブラリ | **jsQR**（純 JS・依存なし・約 280KB・Apache-2.0。GPL-3.0 に同梱できる）。main で `capturePage` の画像をそのまま読む（renderer を往復しない）。Electron 41 には `BarcodeDetector` が無い（`enableBlinkFeatures: 'ShapeDetection'` でも `undefined`。実測）。zxing-wasm は約 3.7MB で WASM を抱えるので見送り |
| コードの更新 | ポップアップが開いている間だけ、**1 秒ごとに表示中の TOTP の id を main に渡し、main がコードと残り秒数を返す**。秘密鍵は renderer に渡さない（詳細の「表示」と編集を開いたときだけ） |
| ページに入れる条件 | ログインと同じく、**TOTP の URL が「入れる先のフレーム」の URL に合うときだけ入れ、合わなければコピーする**。入れる欄は「フォーカス中の入力欄 → 見えている `autocomplete=one-time-code` の欄」の順。入れる先のフレームはフォーカスのあるフレーム（メインか直下の iframe） |

## ログ
### 試したこと・わかったこと
- kypr（`5f0a389`）を `export-nemo` した直後は、`src/main/kypr/index.ts` の 2 か所で型検査が落ちた（「知っている種類でなければ error」の分け方に `totp` が増えたため）。Phase 2 で直した
- Electron 41 には `BarcodeDetector` が無い（`enableBlinkFeatures: 'ShapeDetection'` でも `undefined`）。jsQR を `dependencies` に足した（`mise run licenses` 通過）
- **QR は縮めずに読む**: 最初は長い辺を 2000px に縮めていたが、検証のウィンドウ（1020×820・Retina）の 2040×1640 を 2000px に縮めると、otpauth の QR（升目が細かい）だけ読めなかった（撮った画像を書き出して単独で確かめた。`quality: 'good'` や 1020 / 1500px なら読めた）。縮めずに読み、読めなければちょうど半分にして読み直す形にした
- 自走検証（`mise run verify:only kypr`）: 106 件中 106 件 PASS（TOTP の検査 15 件を足した。TOTP は節の最後に片付けるので、後ろの件数の検査は変わらない）。コードは node:crypto で独立に計算した値と突き合わせた
- ポップアップの見た目（このページの TOTP・「コード」の一覧・詳細・編集）は、検証の途中で一時的に撮ったスクリーンショットで確かめた（撮る処理はコミットに入れていない）

### 方針変更
- ポップアップからログインを入れたときの「コードをコピーしました」の知らせは出していない（入れたらポップアップを閉じるため。⌘⇧L・欄の下の候補から入れたときも同じ）。コピーはされる
- ワンタイムコードの入力は、6 桁の欄が 1 桁ずつに分かれている形には対応していない（1 つの欄にだけ入れる。入れられなければコピーに回る）
