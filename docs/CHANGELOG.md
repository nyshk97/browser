# Changelog

Nemo の変更履歴。**GitHub Release の本文とアプリ内の更新通知の唯一の源**で、
`mise run release` がこのファイルから機械的に切り出す。

## 書き方

- **ユーザーが目視で気づく変更だけ**書く（リファクタリング・CI の調整は書かない）
- 体言止めで1行1件。カテゴリは `追加` / `変更` / `修正` の3つ
- 書き溜めるのは `[Unreleased]` セクション。**リリース時にまとめて書く**
  （コミットごとに書くルールは置かない。書き忘れが信頼を壊すため）
- 内部的な変更だけのリリースは `- 内部的な変更のみ` の1行を書く

```markdown
## [Unreleased]

### 追加

- 新しくできるようになったこと

### 修正

- 直した不具合
```

## [Unreleased]

## [0.2.0] - 2026-08-25

### 追加

- 直近に使ったタブを辿るタブスイッチャー（⌃M）。押している間だけ帯が出て、⌃ を離すと切り替わる
- 履歴とアーカイブを検索できるライブラリ（⌘Y）。履歴は日本語のタイトルでも部分一致で引ける
- 一時タブの自動アーカイブ（既定 24 時間）。タブは閉じるが消えず、ライブラリから開き直せる
- シークレットウィンドウ（⌘⇧P）。履歴も cookie も残さない。拡張は動かない（Bitwarden の自動入力は使えない）
- 設定画面（⌘,）。タブの sleep / 自動アーカイブ・検索エンジン・既定ブラウザの設定をここから触れる
- 既定ブラウザにできるようになった。他のアプリで踏んだリンクが Nemo で開く
- Arc のピン留め・Favorites・フォルダ階層を取り込むコマンド（`mise run arc:import`）
- 設定とピン留めを 2 台目と同期するコマンド（`mise run config:push` / `config:pull`）
- 拡張に新しい版が出ていないか確認するコマンド（`mise run ext:outdated`）

### 修正

- Google Meet などでマイク・カメラが使えなかった問題。Nemo で許可すると macOS 側の許可も求めるようになった
- 画面共有（`getDisplayMedia`）ができなかった問題。macOS の共有ピッカーで画面やウインドウを選べる

## [0.1.1] - 2026-08-23

### 修正

- ダウンロードした dmg を開くときに Gatekeeper の警告が出るのを直した（dmg 自体を署名・公証するようにした）

## [0.1.0] - 2026-08-23

### 追加

- 最初のリリース。Arc の代替として一日ブラウジングできる状態の Nemo
- サイドバー3層（Favorites / ピン留め / 一時タブ）。ピン留めはフォルダで入れ子にでき、ドラッグ & ドロップで並べ替えられる
- コマンドバー（⌘T で新しいタブ・⌘L で今のタブ）。開いているタブ・ピン留め・履歴から候補を出す
- Chrome 拡張のロード（Bitwarden など）。`extensions.lock.json` に固定した artifact だけを読む
- ダウンロード（進捗表示・Finder で表示・保存先を毎回聞く設定）
- セッション復元（終了時のウィンドウとタブを次の起動で戻す。クラッシュした後も同じ経路で戻る）
- 権限ダイアログ（位置情報・通知・カメラ / マイク・画面共有）、HTTP 認証と証明書エラーのダイアログ
- ページ内検索（⌘F）と、二本指スワイプでの戻る / 進む
- 非アクティブなタブの自動 sleep（メモリを解放し、選び直したときに読み直す）
- 履歴の記録と、コマンドバーからの履歴検索
- アプリ内自動更新。新しい版を自動で取得し、サイドバー左下のバージョン表示から再起動して適用する
