# Changelog

Nemo の変更履歴。**GitHub Release の本文とアプリ内の更新通知の唯一の源**で、
`mise run release` がこのファイルから機械的に切り出す。

## 書き方

- **ユーザーが目視で気づく変更だけ**書く（リファクタリング・CI の調整は書かない）
- 体言止めで1行1件。カテゴリは `追加` / `変更` / `修正` の3つ
- 書き溜めるのは `[Unreleased]` セクション。**リリース時にまとめて書く**
  （コミットごとに書くルールは置かない。書き忘れが信頼を壊すため）
- 内部的な変更だけのリリースは `- 内部的な変更のみ` の1行を書く

```markdown
## [Unreleased]

### 変更

- **設定画面を減らした**。タブの sleep / 自動アーカイブ・起動時の復元・ダウンロード先・検索エンジン・キーバインドの各項目と「サイドバーに Pull Request を出す」のトグルを画面から外した（値は既定のまま。変えたいときは `settings.json` を直接編集する）。サイドバーの PR 節を右クリックで隠す項目も無くした
- **「Nemo を既定のブラウザにする」ボタンを無くした**。既定ブラウザは macOS のシステム設定（デスクトップとDock → デフォルトのWebブラウザ）で選ぶ

### 追加

- 新しくできるようになったこと

### 修正

- 直した不具合
```

## [1.5.2] - 2026-09-29

### 追加

- **kypr の Web 版（kypr.tools97.com）を Nemo でも Touch ID で解除できるようにした**。Web 版の「Touch ID を有効にする」が Nemo でも出る。有効にしたあとは、Chrome や Safari と同じくロック画面の指紋のボタンで解除できる（Touch ID を閉じるとマスターパスワードに回る）。シークレットウィンドウでは使えない。ほかのサイトのパスキーは引き続き使えない

## [1.5.1] - 2026-09-29

### 追加

- **英語の住所に都道府県と国も入れられるようにした**。入れておけば英語のフォームでその値を使い、空なら今までどおり都道府県は自動で英語にし（Tokyo など）、国は Japan にする

## [1.5.0] - 2026-09-29

### 追加

- **kypr の個人情報に英語の住所を追加した**（市区町村・番地・建物名）。英語のフォーム（海外のサービスの請求先など）では、フォーム自動入力が氏名をローマ字、住所を英語の住所で入れる（都道府県は Tokyo のように自動で英語にし、国は Japan）。英語の住所が未登録なら住所の欄は空のまま残す
- フォーム自動入力で年齢の欄も入るようにした（生年月日から今日の日付で数える）

## [1.4.0] - 2026-09-29

### 追加

- **kypr に「個人情報」を追加した**。氏名・住所・連絡先・勤務先に加えて、パスポート・運転免許証・健康保険証の番号と有効期限を入れられる。ポップアップ（と Web 版 kypr）で作成・編集でき、身分証の番号は伏せて表示する
- **フォーム自動入力で身分証の番号と有効期限も入る**ようにした。「有効期限」とだけ書いた欄は直前の番号の欄から書類を決め、カード払いの有効期限・発行日・会員番号などには入れない。年の選択肢が和暦（令和◯年）のフォームにも入る

### 変更

- **フォーム自動入力の値の元を kypr の個人情報にした**。iCloud のパスフレーズの保管庫はやめ、設定画面のプロフィールの編集も無くした（kypr のポップアップの「個人情報」で入れ直す）。個人情報が複数あるときは、詳細の「フォーム自動入力に使う」で選ぶ（Mac ごと）
- kypr がロック中にフォーム自動入力を押すと Touch ID で解除して続ける。解除できない・個人情報が無いときは kypr のポップアップが開く
- Jev の API キーは Mac ごとに保存するようにした（別の Mac ではそれぞれ設定画面で入れる）

## [1.3.1] - 2026-09-29

### 変更

- **kypr のポップアップを作り直した**。上にこのページに合うログインのカード（↵ で 1 件目を入力）、下に全件の検索と一覧。色と頭文字のアイコンを Web 版 kypr に揃え、コピーのボタンはカーソルを乗せた行にだけ出す。コピーすると「コピーしました」と出る
- **kypr のポップアップは Esc では閉じず、外をクリックすると閉じる**ようにした（詳細の Esc は一覧へ戻る）。ツールバーのアイコンをもう一度押しても閉じる
- ツールバーの 🔑 を、Web 版・iOS 版の kypr と同じロゴにした。ロック中はロゴが灰色になり錠前が付く

## [1.3.0] - 2026-09-29

### 追加

- **パスワードマネージャー kypr を組み込んだ**。ツールバーの 🔑 に、いま開いているページに合うログインの件数が出る。押すとポップアップが開き、このページのログインを押すと入力される。全件の検索・コピー（30 秒で消える）・ログイン / クレジットカード / セキュアメモの作成と編集・ゴミ箱・完全削除もここでできる
- **⌘⇧L** で、このページに合うログインが 1 件ならそのまま入力する（2 件以上ならポップアップを開く）
- ログイン欄をクリックすると、欄のすぐ下に合うログインが出る（押すと入る）
- 初回は設定の「kypr」かポップアップでマスターパスワードを入れてログインする。2 回目からは Touch ID で解除できる。画面ロック・スリープ・1 時間使わなかったときにロックする
- シークレットウィンドウでも使える

### 変更

- **Bitwarden 拡張を外した**。パスワードは Nemo に組み込んだ kypr で入れる。**パスキーは kypr の次の段階で入れるまで Nemo では使えない**（パスキーしか登録していないアカウントには Nemo から入れない。多くのサイトはパスワードでのログインに切り替えられる）。シークレットウィンドウのサイドバーの注記を「拡張は動かない（kypr は使える）」にした

## [1.2.26] - 2026-09-28

### 変更

- Claude のウィンドウの状態バーで、ログイン等を頼まれているときの表示を「あなたの番です」から「Claude 操作待ち」にした

## [1.2.25] - 2026-09-28

### 変更

- Claude のウィンドウのサイドバーから「cookie が残っているサイト」の一覧を無くし、設定画面の「Claude Code からの操作」に「Claude in Nemo の cookie 等を全て削除」を置いた。一覧は広告の cookie で埋まってしまい、どこにログインしているかの判断に使えなかった。押すと「削除する」に変わり、もう一度押すと Claude が操作するウィンドウの cookie とサイトデータ（ログインを含む）を全て消す。普段のウィンドウには影響しない

## [1.2.23] - 2026-09-28

### 変更

- **Claude のウィンドウの上端を 1 行の状態バーにした**。Claude が動いている間は今やっていること（「スクリーンショット」「〜を開いています」など）を出し、止まっている間は「待機中」と出す。あなたの番のときだけ、下に依頼（サイトと Claude の文）が開く。終わったらチャットで「done」と伝える

## [1.2.20] - 2026-09-28

### 追加

- **Claude Code から Nemo を操作できるようにした（Claude in Nemo）**。Claude in Chrome の代わりに、Claude Code のセッションごとに専用の「Claude — <プロジェクト名>」ウィンドウを開いて操作する。普段のウィンドウ・ログイン・拡張には触れず、前面も奪わない。Claude Code を終えるとウィンドウは閉じる。設定（⌘,）の「Claude Code からの操作を許可」を ON にし、`claude mcp add-json` で登録して使う（docs/operations.md）

## [1.2.5] - 2026-09-02

### 修正

- **Microsoft（login.live.com / Teams）のサインインでパスキーを選ぶとページ全体がクリック無反応になった**。Nemo は Touch ID / iCloud キーチェーンのパスキーに未対応なのに、サイトが出すパスキーのサインイン要求（WebAuthn）が解決も拒否もされず永久に宙吊りになり、サイト側の「待ち」表示が消えなかった。端末内蔵のパスキーでしか答えられないサインイン要求（`get`）には Chrome が最終的に返すのと同じエラー（NotAllowedError）を即返すようにし、サイトがパスワード等の別の方法に進めるようにした。Bitwarden 拡張のパスキーは従来どおり拡張側が先に処理し、保管庫に無い・キャンセルで拡張がブラウザへ戻したサインイン要求もここで即エラーになる。パスキーの新規登録（`create`）は端末内蔵を指定した要求だけ即エラーで、指定の無い要求は通す。通した要求（USB セキュリティキー向け・登録の指定無し）は要求の timeout（10 秒〜10 分、無指定は 60 秒）で打ち切る。Nemo で USB セキュリティキーが実際に使えるかは未確認。Touch ID / iCloud キーチェーンのパスキーは引き続き使えない

## [0.6.0] - 2026-08-28

### 追加

- **ページ上で `gg` / `G` を押すと縦の端へ飛べるようになった**（vim の作法）。`g` を1秒以内に2回で最上部、`G`（Shift+g）で最下部。なめらかにスクロールする（OS の「視差効果を減らす」が有効なら即時）。Gmail や Slack のように**ページのルートが動かず内側の領域がスクローラ**になっているサイトでも効く。入力欄・IME 変換中・修飾キー付きのときは効かず、キー自体はページにも渡すので GitHub の `g c` や Gmail の `g i` は今までどおり使える
- **HTTP Basic 認証を自動で入力できるようになった**。認証ダイアログで「次回から自動で入力する」を選ぶと、そのオリジンに資格情報が紐づき、次からはダイアログが出ずに通る。保存した資格情報が拒否されたときは、その値を入れた状態でダイアログが出るので、直して保存し直せば上書きされる。設定 > Basic 認証 でパターン（正規表現）の編集・パスワードの確認・有効/無効の切り替えができ、URL を入れて「どのルールが使われるか」を試せる。MultiPass のエクスポート JSON をそのまま貼り付けて取り込むこともできる。パスワードは端末鍵で暗号化して保存し、他端末とは同期しない（シークレットウィンドウでは読み書きとも一切しない）
- **ピン留めとお気に入りを 3 つの枠に保存して、別の Mac で読み込めるようになった**（設定 > ブックマークのセーブスロット）。保存先は iCloud Drive なので、2 台目の Nemo を開けば同じ 3 枠がそのまま見える。カードには名前・保存日時・保存した Mac・件数・アイコンが出て、名前はクリックでその場編集できる。読み込むと、そのマシンのピン留めとお気に入りが**まるごと入れ替わる**（元には戻せないので確認を 1 回挟む）。読み込んだ枠に無いピン留め・お気に入りを開いていたタブは、名前を保ったまま「今日のタブ」に移る（ページは閉じない）。上書き保存はできず、上書きしたいときは「削除」してから同じ枠に「保存」する
- **タブを左右に並べて見られるようになった**。サイドバーのタブ行を別のタブ行の真ん中へドラッグすると、その 2 本が左右に並ぶ（落とした先が左）。並べたタブはサイドバーで 1 行にまとまり、右クリックの「分割を解除」で元の 2 行に戻る（左だったタブが上・右だったタブが下）。ペインごとにアドレスバーが付き、操作中のペインは青い枠で分かる。再起動しても並びは復元される。並べられるのは今日のタブ同士だけで、ピン留めしたタブは対象外（ピン留めすると並びは解ける）

### 変更

- 設定とピン留めを 2 台目と同期するコマンド（`mise run config:push` / `config:pull` / `config:status` / `config:init` / `config:restore`）を廃止した。ブックマークのセーブスロットに一本化したため。`settings.json`（キーバインドを含む）は同期の対象から外れる

## [0.2.0] - 2026-08-25

### 追加

- 直近に使ったタブを辿るタブスイッチャー（⌃M）。押している間だけ帯が出て、⌃ を離すと切り替わる
- 履歴とアーカイブを検索できるライブラリ（⌘Y）。履歴は日本語のタイトルでも部分一致で引ける
- 一時タブの自動アーカイブ（既定 24 時間）。タブは閉じるが消えず、ライブラリから開き直せる
- シークレットウィンドウ（⌘⇧P）。履歴も cookie も残さない。拡張は動かない（Bitwarden の自動入力は使えない）
- 設定画面（⌘,）。タブの sleep / 自動アーカイブ・検索エンジン・既定ブラウザの設定をここから触れる
- 既定ブラウザにできるようになった。他のアプリで踏んだリンクが Nemo で開く
- Arc のピン留め・Favorites・フォルダ階層を取り込むコマンド（`mise run arc:import`）
- 設定とピン留めを 2 台目と同期するコマンド（`mise run config:push` / `config:pull`）
- 拡張に新しい版が出ていないか確認するコマンド（`mise run ext:outdated`）

### 修正

- Google Meet などでマイク・カメラが使えなかった問題。Nemo で許可すると macOS 側の許可も求めるようになった
- 画面共有（`getDisplayMedia`）ができなかった問題。macOS の共有ピッカーで画面やウインドウを選べる

## [0.1.0] - 2026-08-23

### 追加

- 最初のリリース。Arc の代替として一日ブラウジングできる状態の Nemo
- サイドバー3層（Favorites / ピン留め / 一時タブ）。ピン留めはフォルダで入れ子にでき、ドラッグ & ドロップで並べ替えられる
- コマンドバー（⌘T で新しいタブ・⌘L で今のタブ）。開いているタブ・ピン留め・履歴から候補を出す
- Chrome 拡張のロード（Bitwarden など）。`extensions.lock.json` に固定した artifact だけを読む
- ダウンロード（進捗表示・Finder で表示・保存先を毎回聞く設定）
- セッション復元（終了時のウィンドウとタブを次の起動で戻す。クラッシュした後も同じ経路で戻る）
- 権限ダイアログ（位置情報・通知・カメラ / マイク・画面共有）、HTTP 認証と証明書エラーのダイアログ
- ページ内検索（⌘F）と、二本指スワイプでの戻る / 進む
- 非アクティブなタブの自動 sleep（メモリを解放し、選び直したときに読み直す）
- 履歴の記録と、コマンドバーからの履歴検索
- アプリ内自動更新。新しい版を自動で取得し、サイドバー左下のバージョン表示から再起動して適用する
