# Changelog

Nemo の変更履歴。**GitHub Release の本文とアプリ内の更新通知の唯一の源**で、
`mise run release` がこのファイルから機械的に切り出す。

## 書き方

- **ユーザーが目視で気づく変更だけ**書く（リファクタリング・CI の調整は書かない）
- 体言止めで1行1件。カテゴリは `追加` / `変更` / `修正` の3つ
- 書き溜めるのは `[Unreleased]` セクション。**リリース時にまとめて書く**
  （コミットごとに書くルールは置かない。書き忘れが信頼を壊すため）
- 内部的な変更だけのリリースは `- 内部的な変更のみ` の1行を書く

```markdown
## [Unreleased]

### 変更

- **設定画面を減らした**。タブの sleep / 自動アーカイブ・起動時の復元・ダウンロード先・検索エンジン・キーバインドの各項目と「サイドバーに Pull Request を出す」のトグルを画面から外した（値は既定のまま。変えたいときは `settings.json` を直接編集する）。サイドバーの PR 節を右クリックで隠す項目も無くした
- **「Nemo を既定のブラウザにする」ボタンを無くした**。既定ブラウザは macOS のシステム設定（デスクトップとDock → デフォルトのWebブラウザ）で選ぶ

### 追加

- 新しくできるようになったこと

### 修正

- 直した不具合
```

## [Unreleased]

### 追加

- **リンクをポップアップ（Peek）で開いたとき、中身が来るまでの板に行き先のホスト名と頭文字・読み込み中のドットが出る**。今までは暗い板が止まって見えるだけで、読み込んでいるのか固まっているのか分からなかった
- **ローカルの HTML を開ける**。Finder のダブルクリック・`open <path>`・アドレスバーへのパス入力（`/…` `~/…` `file://…`）から開く。Finder / `open` は小窓で開き、⌘O でタブに昇格できる。Web ページや拡張が起点の `file:` は今までどおり開かない。ローカル HTML の中の iframe は表示されず、ローカルファイルのタブは再起動で復元されない

### 修正

- **アドレスバーで開けない入力（`javascript:` 等）を入れたとき無言だったのを直した**。入力がそのまま残り、赤枠と理由が出る

## [1.2.5] - 2026-09-02

### 修正

- **Microsoft（login.live.com / Teams）のサインインでパスキーを選ぶとページ全体がクリック無反応になった**。Nemo は Touch ID / iCloud キーチェーンのパスキーに未対応なのに、サイトが出すパスキーのサインイン要求（WebAuthn）が解決も拒否もされず永久に宙吊りになり、サイト側の「待ち」表示が消えなかった。端末内蔵のパスキーでしか答えられないサインイン要求（`get`）には Chrome が最終的に返すのと同じエラー（NotAllowedError）を即返すようにし、サイトがパスワード等の別の方法に進めるようにした。Bitwarden 拡張のパスキーは従来どおり拡張側が先に処理し、保管庫に無い・キャンセルで拡張がブラウザへ戻したサインイン要求もここで即エラーになる。パスキーの新規登録（`create`）は端末内蔵を指定した要求だけ即エラーで、指定の無い要求は通す。通した要求（USB セキュリティキー向け・登録の指定無し）は要求の timeout（10 秒〜10 分、無指定は 60 秒）で打ち切る。Nemo で USB セキュリティキーが実際に使えるかは未確認。Touch ID / iCloud キーチェーンのパスキーは引き続き使えない

## [1.2.4] - 2026-09-01

### 変更

- **⌘1〜9 が `tools` の Favorites だけを指すようになった**。今までは `messages` → `tools` の通し番号で、`messages` の件数が変わると `tools` の番号がずれていた。`messages` に番号は付かない（⌘長押しの番号バッジも `tools` だけに出る）。あわせてサイドバーの並びを `tools` が上・`messages` が下に入れ替えた（空セクションもドラッグの受け皿を出す。Favorites が 1 件も無い初回だけ `messages` を畳む）

## [1.2.3] - 2026-08-31

### 変更

- **再読み込みボタン（⟳）の右クリックがメニューになった**。今までは右クリックで即キャッシュ無視の再読み込みが走っていた（見た目の区別が無く効いたか分からない）のを、Chrome と同じく「通常の再読み込み / ハード再読み込み」を選ぶメニューに変えた

### 修正

- **スリープ中のタブに ⌘⇧R（ハード再読み込み）が無反応だった**。⌘R と同じく、まず起こすようにした（起こすだけでキャッシュ無視まではしない。必要なら起きてからもう一度 ⌘⇧R）

## [1.2.2] - 2026-08-31

### 修正

- **入力途中のフォームなど「ページを離れますか？」を出すサイトで、リロード（⌘R / ⟳）やページ遷移が何も出ずに無反応だった**。beforeunload で離脱をガードするページに対し、Chrome と同じ確認ダイアログ（このページを離れる / キャンセル）を出して続行できるようにした

## [1.2.1] - 2026-08-31

### 修正

- **Teams が「クラシック Teams は使用できなくなりました」で開けない**。User-Agent の `Electron/…` トークンを旧 Teams デスクトップアプリと誤判定されてエラーページに飛ばされていた。トークンを取り除き、新クライアント（`/v2`）に到達するようにした。Google ログインなど Electron を弾く他サイトにも効く
- **ポップアップ（Peek）を見ている間のコマンドが裏の親タブに効いていた**。⌘L のアドレスバーに親タブの URL が出る・編集して確定すると親タブが遷移する、を修正し、前面の Peek が対象になるようにした。再読み込み（⌘R / ⇧⌘R）・戻る / 進む・URL をコピー・拡大縮小・ページ内検索（⌘F）・デベロッパーツール・⌘L → Esc 後のフォーカスも同様に Peek に効く。ページ内検索のバーは見ているページが変わったら閉じるようにした（Peek を閉じた・検索中に別のタブへ切り替えた等。⌘O で昇格したときは同じページの検索がそのまま続く）

## [1.2.0] - 2026-08-31

### 変更

- **一時タブがウィンドウ横断で共有されるようになった（Arc 風）**。どのウィンドウで開いたタブも全ウィンドウのサイドバーに出て、まだ実体の無いウィンドウでは薄い行になりクリックで開く。アクティブ選択とページ実体はウィンドウごとに独立（同じタブを 2 枚のディスプレイで並べて開ける）。閉じる（⌘W・×）と全ウィンドウから消え、ウィンドウを閉じただけでは消えない。シークレット・小窓は共有に参加しない（小窓は ⌘O 合流時点で共有入り）。別ウィンドウで Meet に参加中のタブは二重に開かず、そのウィンドウへフォーカスが移る
- **「タブを新規ウィンドウへ」（⌘⇧N）を廃止**。新規ウィンドウにも全タブが出るため

## [1.1.0] - 2026-08-31

### 追加

- **Favorites とブックマークの URL を直接書き換えられる**。右クリックの「URLを変更…」で、枠を押したとき開く URL を任意の URL に差し替えられる（Arc の Edit Pinned URL 相当。Google カレンダーの `u/3/r` を `?authuser=…` 形式にする、のような用途）。タブが閉じていても使え、別の枠と重複する URL や http/https 以外は保存せずエラーを出す。「このページに更新」も Favorites で使えるようにした

### 修正

- **まっさらな状態（新しい PC・シークレットウィンドウ）の Google Meet が「マイクが見つかりません」で詰む**。マイク・カメラをまだ許可も拒否もしていないのに `permissions.query` へ「許可済み」と答えていたため、Meet がデバイス無しと解釈して許可ダイアログまで進めなかった。未決定は「未決定（prompt）」と答えるようにし、許可フロー（Nemo → macOS のダイアログ）に正しく進めるようにした

## [1.0.2] - 2026-08-31

### 変更

- **ダウンロードのたびに保存先を確認するようにした**。ダイアログでキャンセルするとダウンロードを中止する。黙って `~/Downloads` に保存する従来の挙動（`settings.json` の `askDownloadLocation`）は設定ごと廃止

## [1.0.1] - 2026-08-31

### 変更

- **起動直後に空の「New Tab」を作らない**。復元するセッションが無いときはタブ無しの空状態で開き、最初のタブは ⌘T やサイドバーから作る
- **ページの言語を OS の言語に合わせる**。これまで OS が日本語でも `navigator.language` / `Accept-Language` が `en-US` 先頭で送られ、サイトが英語で出ていた

### 修正

- **システム設定「デフォルトの Web ブラウザ」の候補に Nemo が出ない**。HTML 書類を開ける宣言が無かったため、http/https を登録していても候補に載らなかった（パッケージの再インストールで反映）

## [1.0.0] - 2026-08-30

### 追加

- **ページ本体の右クリックメニュー**。画像の上で「名前を付けて画像を保存… / 画像をコピー / 画像アドレスをコピー」、どこでも「検証」（その要素を DevTools で開く）が使える。戻る・再読み込み・コピー等のショートカットで済むものは載せない

## [0.10.0] - 2026-08-30

### 追加

- **Favorites とブックマークにアイコンを付けられる**。右クリックの「アイコンを変更…」から絵文字（欄に 1 つ入れて Enter。⌃⌘Space の絵文字パネルも使える）か画像（「🖼 画像…」またはタイルへ画像ファイルをドロップ。64px の PNG に縮めて保存）を設定でき、同じサービスのタイルが並んでも見分けられる。プレビューの × で favicon に戻る。ブックマークを Favorites に移しても（その逆も）アイコンは引き継がれる

## [0.9.0] - 2026-08-30

### 変更

- **サイドバーの並びを Pull Request → Favorites → ブックマーク → タブ にした**（Favorites が Live Folder の下に来る）。見出しは `messages` / `tools` / `bookmarks` の薄いラベルで揃え、ピンのアイコンは無くした
- **Favorites を `messages` と `tools` の 2 セクションに分けた**。既存の Favorites・Arc からの取り込み・新規追加はすべて `tools` に入る。`messages` へはタイルのドラッグか右クリックの「Messages へ移動」で振り分ける
- **⌘1〜9 の意味が変わった**。一時タブの N 番目ではなく **Favorites の N 番目**（`messages` → `tools` の通し番号）を開く。すでにそのタブを見ているときにもう一度押すと直前のタブへ戻る。⌘ を押し続けるとタイルに番号が出る

### 修正

- **ピン留め・Favorites のアイコンが、タブを開くまで頭文字のままだった**。favicon をブックマーク側に覚えるようにし、起動直後から（履歴を消しても）アイコンで見分けられる。既存のブックマークは履歴に残っている favicon で埋める

## [0.8.2] - 2026-08-30

### 修正

- **Bitwarden を popup で解除した直後から、ツールバーのアイコンとログイン欄の候補（インラインメニュー）が解除状態になる**。Electron が拡張の service worker で `chrome.storage` の変更通知（`onChanged`）を鳴らさないため、解除しても SW が再起動するまで「ロック中」のままだった。Nemo 側で通知を補うようにした
- Bitwarden の Autofill 設定（候補の表示など）を popup で変えると、**再起動なしで効く**ようになった（同じ原因）

## [0.8.1] - 2026-08-30

### 追加

- **Homebrew で入れられるようになった**（`brew install --cask nyshk97/tap/nemo`）。リリースのたびに cask も自動で更新される

### 変更

- **ツールバー右上の拡張アイコンを Bitwarden だけにした**。Keepa や GraphQL Network Inspector のようにページ側で勝手に働く拡張は、有効でもアイコンを出さない（拡張自体は動いている）。どれを出すかは `extensions.lock.json` の `showInToolbar` で決める
- **サイドバー左下の拡張一覧を無くした**。⚙ とバージョン表示だけになる。拡張の一覧・ON/OFF・「lock 不一致」の警告は設定画面（⌘,）の「Chrome 拡張」で見る
- **未読ドット（タブ行右端の青い点）を無くした**。バックグラウンドで読み込みが終わってもタブ・ピン留め・お気に入り・Pull Request 一覧のどこにも点を出さない

## [0.8.0] - 2026-08-30

### 追加

- **拡張を端末ごとに ON/OFF できるようになった**。設定画面の「Chrome 拡張」に各拡張のチェックボックスが付き、再起動なしで切り替わる（`settings.json` の `extensions.disabled` に保存。新しい PC では全部 ON）。OFF にした拡張はサイドバーのフッターから消える。切り替えたあと、開いているページはリロードが必要（DevTools は開き直し）。OFF→ON は拡張の再起動にも使える（`chrome.storage.local` の設定は残る）
- **GraphQL Network Inspector が入った**。DevTools に「GraphQL Network」パネルが増え、HTTP 経由の GraphQL（Query / Mutation）が一覧になる。WebSocket（Subscriptions）タブは常に空（Electron に `chrome.debugger` が無いため。Nemo は空実装を拡張ページにだけ生やしている）
- **Keepa（Amazon の価格推移グラフ）が入った**。Amazon の商品ページを開くと、商品画像の下に価格の推移と最安値の履歴が出る。Chrome Web Store にしか無い拡張を lock に載せられるようになった（`chrome-web-store` ソース）ので、今後も Web Store 配布の拡張を同じ手順で足せる

## [0.7.0] - 2026-08-29

### 追加

- **メモリ・CPU を 5 分おきに診断ログへ記録するようになった**（`metrics.sample`。プロセス種別ごとの合計と、重い renderer 上位 5 件をタブに紐づけて残す）。`mise run metrics:report` で日別に集計できる。起動時（ready までの時間・復元タブ数・拡張数）と終了時（稼働時間・その時点の負荷）も残す。ブラウザ UI で起きた例外も `ui.error` としてログに残るようになった
- **Basic 認証のルールを別の Mac へ引き継げるようになった**（設定 > Basic 認証の引き継ぎ）。「保存」でこの Mac の有効なルールをまとめて保管庫に書き出し、別の Mac の「読み込む」で受け取る。保存先はセーブスロットと同じ iCloud のフォルダ。パスワードは端末鍵では別の Mac で開けないので、**保存のときに決めたパスフレーズで暗号化**して運ぶ（パスフレーズはこの Mac に覚えさせておける）。読み込むときは「この Mac に無いもの / 内容が違うもの / 既にあるもの」の 3 つに分かれて出るので、**必要なものだけチェックして入れられる**。この Mac で無効にしてあるルールは「既にあるもの」に出て、勝手に有効へ戻ることはない。保存は全件の置き換えなので、保管庫にしか無いルールがあれば消える前に名前を出して確認する。パスフレーズを変えたいときは保管庫を削除してから保存し直す

## [0.6.0] - 2026-08-28

### 追加

- **ページ上で `gg` / `G` を押すと縦の端へ飛べるようになった**（vim の作法）。`g` を1秒以内に2回で最上部、`G`（Shift+g）で最下部。なめらかにスクロールする（OS の「視差効果を減らす」が有効なら即時）。Gmail や Slack のように**ページのルートが動かず内側の領域がスクローラ**になっているサイトでも効く。入力欄・IME 変換中・修飾キー付きのときは効かず、キー自体はページにも渡すので GitHub の `g c` や Gmail の `g i` は今までどおり使える
- **HTTP Basic 認証を自動で入力できるようになった**。認証ダイアログで「次回から自動で入力する」を選ぶと、そのオリジンに資格情報が紐づき、次からはダイアログが出ずに通る。保存した資格情報が拒否されたときは、その値を入れた状態でダイアログが出るので、直して保存し直せば上書きされる。設定 > Basic 認証 でパターン（正規表現）の編集・パスワードの確認・有効/無効の切り替えができ、URL を入れて「どのルールが使われるか」を試せる。MultiPass のエクスポート JSON をそのまま貼り付けて取り込むこともできる。パスワードは端末鍵で暗号化して保存し、他端末とは同期しない（シークレットウィンドウでは読み書きとも一切しない）
- **ピン留めとお気に入りを 3 つの枠に保存して、別の Mac で読み込めるようになった**（設定 > ブックマークのセーブスロット）。保存先は iCloud Drive なので、2 台目の Nemo を開けば同じ 3 枠がそのまま見える。カードには名前・保存日時・保存した Mac・件数・アイコンが出て、名前はクリックでその場編集できる。読み込むと、そのマシンのピン留めとお気に入りが**まるごと入れ替わる**（元には戻せないので確認を 1 回挟む）。読み込んだ枠に無いピン留め・お気に入りを開いていたタブは、名前を保ったまま「今日のタブ」に移る（ページは閉じない）。上書き保存はできず、上書きしたいときは「削除」してから同じ枠に「保存」する
- **タブを左右に並べて見られるようになった**。サイドバーのタブ行を別のタブ行の真ん中へドラッグすると、その 2 本が左右に並ぶ（落とした先が左）。並べたタブはサイドバーで 1 行にまとまり、右クリックの「分割を解除」で元の 2 行に戻る（左だったタブが上・右だったタブが下）。ペインごとにアドレスバーが付き、操作中のペインは青い枠で分かる。再起動しても並びは復元される。並べられるのは今日のタブ同士だけで、ピン留めしたタブは対象外（ピン留めすると並びは解ける）

### 変更

- 設定とピン留めを 2 台目と同期するコマンド（`mise run config:push` / `config:pull` / `config:status` / `config:init` / `config:restore`）を廃止した。ブックマークのセーブスロットに一本化したため。`settings.json`（キーバインドを含む）は同期の対象から外れる

### 修正

- 別タブで開くリンクを踏んでから、ポップアップ（Peek）の窓が出るまでに間があった問題。踏んだ瞬間に窓の形が出るようにした

## [0.5.2] - 2026-08-27

### 変更

- サイドバーの Pull Request の小見出し（`REVIEW REQUESTED` / `CREATED`）を押すと、それぞれ独立に折りたためるようにした。起動時は両方畳まれた状態から始まる（PR が多いとサイドバーの大半を占めていたため）。畳んでいる間に未読の PR があれば、件数の横に未読ドットが出る

## [0.5.1] - 2026-08-26

### 修正

- 起動した直後の 60 秒間、サイドバーの Pull Request が `Connect GitHub`（未設定）に見えていた問題。起動直後の1回目だけ `gh auth token` の呼び出しに 2.6 秒かかり、内部の待ち時間（3 秒）に間に合わずに「未設定」へ落ちていた

## [0.5.0] - 2026-08-26

### 追加

- サイドバーに **GitHub の Pull Request が勝手に並ぶセクション**。「自分にレビュー依頼が来ている PR」と「自分が作った未マージの PR」が Favorites の直下に出て、マージされれば勝手に消える。行を押すとその PR のタブへ切り替わり（無ければ開く）、新しく現れた PR には未読ドットが付く
- PR の行に状態バッジ。緑チェック = Approved / 黄 = 要修正 / グレー = Draft / バッジ無し = レビュー待ち。2行目は「レビュー依頼」なら著者名、「自分の PR」ならリポジトリ名
- 取得に失敗しても一覧は消さず、末尾の行に「いつの内容か」を出すようにした（`Couldn't refresh · showing 19:12`）。レート制限中は残り時間を出し、更新ボタンは出さない（押しても投げないため）
