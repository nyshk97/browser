# Changelog

Nemo の変更履歴。**GitHub Release の本文とアプリ内の更新通知の唯一の源**で、
`mise run release` がこのファイルから機械的に切り出す。

## 書き方

- **ユーザーが目視で気づく変更だけ**書く（リファクタリング・CI の調整は書かない）
- 体言止めで1行1件。カテゴリは `追加` / `変更` / `修正` の3つ
- 書き溜めるのは `[Unreleased]` セクション。**リリース時にまとめて書く**
  （コミットごとに書くルールは置かない。書き忘れが信頼を壊すため）
- 内部的な変更だけのリリースは `- 内部的な変更のみ` の1行を書く

```markdown
## [Unreleased]

### 追加

- 新しくできるようになったこと

### 修正

- 直した不具合
```

## [Unreleased]

### 修正

- 起動した直後の 60 秒間、サイドバーの Pull Request が `Connect GitHub`（未設定）に見えていた問題。起動直後の1回目だけ `gh auth token` の呼び出しに 2.6 秒かかり、内部の待ち時間（3 秒）に間に合わずに「未設定」へ落ちていた

## [0.5.0] - 2026-08-26

### 追加

- サイドバーに **GitHub の Pull Request が勝手に並ぶセクション**。「自分にレビュー依頼が来ている PR」と「自分が作った未マージの PR」が Favorites の直下に出て、マージされれば勝手に消える。行を押すとその PR のタブへ切り替わり（無ければ開く）、新しく現れた PR には未読ドットが付く
- PR の行に状態バッジ。緑チェック = Approved / 黄 = 要修正 / グレー = Draft / バッジ無し = レビュー待ち。2行目は「レビュー依頼」なら著者名、「自分の PR」ならリポジトリ名
- 取得に失敗しても一覧は消さず、末尾の行に「いつの内容か」を出すようにした（`Couldn't refresh · showing 19:12`）。レート制限中は残り時間を出し、更新ボタンは出さない（押しても投げないため）
- 設定画面に GitHub の接続先。**Personal Access Token を貼ると端末の鍵で暗号化して保存する**（貼らなければ `gh auth token` を使う）。サイドバーのセクションを隠す / 戻すトグルもここ

## [0.4.1] - 2026-08-25

### 修正

- 会議の小窓のマイク・カメラを押しても、**会議タブに戻るまで実際には切り替わらなかった**問題。背面のタブでは Chromium が描画を止めるため、Meet 側の反映が保留されていた
- 会議の小窓を掴んで動かせる余白がほとんど無かった問題。枠を広げて、ボタンのあいだと外周を掴みしろにした

### 変更

- 会議の小窓の「戻る」を、**ドメイン名と経過時間ごと押せるボタン**にした（何に戻るのか分かるようにするため）
- 会議の小窓から ✕ を外した。会議中はいつでも出ている

## [0.4.0] - 2026-08-25

### 追加

- 会議の小窓。Google Meet の会議タブから離れているあいだ、**他アプリの上に浮く小さなバー**が出る。そこから「会議タブへ戻る」「マイクの ON/OFF」「カメラの ON/OFF」ができる（退出ボタンは置いていない）。ドラッグして置いた位置は次から覚える
- 会議中のタブは自動 sleep・自動アーカイブの対象から外れるようになった。全員がミュートで静かな時間が続いても通話が切れない

### 変更

- アドレスバーが**ページ領域の上端**に移った。戻る・進む・再読み込み・拡張・ダウンロード・履歴も同じ行に集まり、サイドバーはタブの一覧だけになる
- サイドバーの1行を高くした（28px → 40px）
- タブに hover したときの閉じる（×）を大きくして押しやすくした
- フォルダの名前は**右クリックの「名前を変更」からだけ**変えられる。ダブルクリックは開閉するだけになった（ピン留め・タブのダブルクリックでのリネームは今までどおり）
- 一時タブの先頭の行と空タブの表示を「新しいタブ」から「New Tab」にした
- タブが 1 つも無いときのページに、魚のマークと ⌘T / ⌘⇧T の表記を出すようにした

### 修正

- **Google Meet でマイクとカメラの許可ダイアログが出せなかった問題**。「マイクの使用がブロックされています」から先へ進めず、許可のしようが無かった。まだ決めていない権限を「拒否済み」として答えていたのが原因（デバイス名が同意なしに漏れないことは保ったまま直した）
- ウィンドウを閉じたときにアドレスバーの描画プロセスが残っていた問題

## [0.3.0] - 2026-08-25

### 追加

- Peek。ページ内の `target=_blank` / `window.open` を、いきなりタブにせず**今見ているページの上に浮かぶポップアップ**で開く。✕ / Esc / ⌘W で閉じ、⌘O でそのままタブに昇格する（読み直さない）
- 小窓（Little Nemo）。ターミナルや Slack から踏んだリンクを、**メインウィンドウを前面に出さずに**今いる画面の上へ小さなウィンドウで開く。⌘O でメインウィンドウのタブへ移る
- 「メインウィンドウで開く」（⌘O）。Peek と小窓の中身を通常のタブへ移す

### 変更

- 外部アプリから踏んだリンクで**画面が Nemo に持っていかれなくなった**。フルスクリーンで作業していても Space は切り替わらず、小窓だけが手前に出る
- `⌘` を押しながらのクリック（背面タブ）は今までどおり。前面に出そうとするリンクだけが Peek になる

### 修正

- `<form target="_blank">` の POST や、`window.opener` 越しのやり取り（OAuth の戻りなど）が落ちていた問題。popup を作り直さずそのまま受け取るようにした

## [0.2.0] - 2026-08-25

### 追加

- 直近に使ったタブを辿るタブスイッチャー（⌃M）。押している間だけ帯が出て、⌃ を離すと切り替わる
- 履歴とアーカイブを検索できるライブラリ（⌘Y）。履歴は日本語のタイトルでも部分一致で引ける
- 一時タブの自動アーカイブ（既定 24 時間）。タブは閉じるが消えず、ライブラリから開き直せる
- シークレットウィンドウ（⌘⇧P）。履歴も cookie も残さない。拡張は動かない（Bitwarden の自動入力は使えない）
- 設定画面（⌘,）。タブの sleep / 自動アーカイブ・検索エンジン・既定ブラウザの設定をここから触れる
- 既定ブラウザにできるようになった。他のアプリで踏んだリンクが Nemo で開く
- Arc のピン留め・Favorites・フォルダ階層を取り込むコマンド（`mise run arc:import`）
- 設定とピン留めを 2 台目と同期するコマンド（`mise run config:push` / `config:pull`）
- 拡張に新しい版が出ていないか確認するコマンド（`mise run ext:outdated`）

### 修正

- Google Meet などでマイク・カメラが使えなかった問題。Nemo で許可すると macOS 側の許可も求めるようになった
- 画面共有（`getDisplayMedia`）ができなかった問題。macOS の共有ピッカーで画面やウインドウを選べる

## [0.1.1] - 2026-08-23

### 修正

- ダウンロードした dmg を開くときに Gatekeeper の警告が出るのを直した（dmg 自体を署名・公証するようにした）

## [0.1.0] - 2026-08-23

### 追加

- 最初のリリース。Arc の代替として一日ブラウジングできる状態の Nemo
- サイドバー3層（Favorites / ピン留め / 一時タブ）。ピン留めはフォルダで入れ子にでき、ドラッグ & ドロップで並べ替えられる
- コマンドバー（⌘T で新しいタブ・⌘L で今のタブ）。開いているタブ・ピン留め・履歴から候補を出す
- Chrome 拡張のロード（Bitwarden など）。`extensions.lock.json` に固定した artifact だけを読む
- ダウンロード（進捗表示・Finder で表示・保存先を毎回聞く設定）
- セッション復元（終了時のウィンドウとタブを次の起動で戻す。クラッシュした後も同じ経路で戻る）
- 権限ダイアログ（位置情報・通知・カメラ / マイク・画面共有）、HTTP 認証と証明書エラーのダイアログ
- ページ内検索（⌘F）と、二本指スワイプでの戻る / 進む
- 非アクティブなタブの自動 sleep（メモリを解放し、選び直したときに読み直す）
- 履歴の記録と、コマンドバーからの履歴検索
- アプリ内自動更新。新しい版を自動で取得し、サイドバー左下のバージョン表示から再起動して適用する
